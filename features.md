# Features – Schnapsen

Status: `[x]` fertig, `[ ]` offen

## Grundlagen (Ziel für den Zwischenstand)

1. [x] **Kartendeck:** 20 Karten erzeugen (Herz, Schelle, Eichel, Laub, je Ass, Zehn, König, Ober, Unter) und zufällig mischen.
2. [x] **Austeilen:** Spieler und Computer bekommen je 5 Karten. Die nächste Karte wird als Trumpf aufgedeckt, der Rest bildet den Talon.
3. [x] **Ausspielen:** Die eigene Hand wird nummeriert angezeigt, der Spieler wählt per Zahleneingabe eine Karte. Ungültige Eingaben werden abgefangen.

## Spielablauf

4. [ ] **Stichauswertung:** Wer gewinnt den Stich (Farbe, Trumpf, Rang)?
5. [ ] **Punktezählung:** Punkte pro Seite mitzählen, Spielende bei 66.
6. [ ] **Nachziehen:** Nach jedem Stich vom Talon nachziehen, Stichgewinner zuerst.
7. [ ] **Ansagen:** 20er und 40er (König und Ober einer Farbe).
8. [ ] **Austausch:** Trumpf-Unter gegen die offene Trumpfkarte tauschen.
9. [ ] **Zudrehen:** Talon schließen; danach Farb- und Stichzwang.

## Gegner und Wertung

10. [ ] **Computergegner:** einfache Strategie (z. B. stechen, wenn möglich, sonst die niedrigste Karte abwerfen).
11. [ ] **Bummerl-Wertung:** 1 bis 3 Spielpunkte pro Spiel, Partie bis 7 Spielpunkte.
12. [ ] **Hauptmenü:** Neues Spiel, Regelerklärung, Beenden.
